# Supplementary item → artefact → script

Every exhibit is generated from files in this release. "Source" identifies the released artefact, and "regenerate" gives the command that rebuilds it. Run commands from the release root after extracting the data packages as described in [REPRODUCE.md](REPRODUCE.md). [RESULTS.md](RESULTS.md) gives the numerical summary.

**Numbering follows the paper**, not this file: Supplementary Notes S1-S5, Supplementary Tables S1-S10 and Supplementary Figures S1-S6, in the order they appear in the supplementary material. Analysis products cited without a number are listed separately and remain unnumbered here.

`data/analysis/sm_tables.tex` is a standalone LaTeX body for inclusion in the paper source. It is produced in one pass:

```bash
python scripts/05_eval/make_sm_tables.py        # -> data/analysis/sm_tables.tex
```

The per-table regeneration command is the same because each table is one section of that generator.

The two hand-drawn exhibits and a copy of the main overview used by the README are committed to the repository:

```
figures/fig1_causal_discovery.{pdf,png}
figures/fig2_architecture.{pdf,png}
figures/fig_main_overview.png
```

Computed analysis products are stored under `data/analysis/`, including `figures_pub/`, `compare/`, and `eval/`.
